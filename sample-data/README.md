# Sample Data

Fictional data for testing data input, file upload, and charts. Each file comes in `.csv` and `.xlsx`.

| File | Columns | Use |
| -- | -- | -- |
| `commute-survey` | Commute, Students | Bar, Pie (6 items) |
| `library-visitors` | Month, Main, East, West | Line, Bar with multiple series (12 months × 3 series) |
| `study-hours` | Student, Study Hours, Score | Scatter (16 points) |
| `product-sales` | Product, Price, Rating, Units Sold | Bubble (6 items) |
| `invalid-data` | Commute, Students | Upload error handling (empty cells, text in a number column) |
